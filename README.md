# 🌸 3D ASCII Flower Bouquet

A colorful, animated 3D bouquet built entirely with Python. Each flower is constructed from ASCII characters and positioned in 3D space to create a bouquet that continuously rotates.

### ✨ Features
- Rotating 3D flower arrangement
- Multi-colored ASCII flowers and foliage
- Custom 3D projection and depth rendering
- Animated desktop window
- Full-window visualization

### 🛠 Built With
- Python
- Tkinter
- 3D geometry & projection
- ASCII art

### ▶️ Run Locally

```bash
python3 bouquet3d.py
```

Created as a creative coding experiment combining programming, geometry, and art. 💐
